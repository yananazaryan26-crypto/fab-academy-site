# Բարի գալուստ իմ պորտֆոլիո

## Բարև ձեզ, ես Յանան եմ 👋

Ուրախ եմ ողջունել ձեզ իմ անհատական վեբ էջում, որը ստեղծվել է Ֆաբ Ակադեմիայի շրջանակներում։ Այս կայքում ես ներկայացնելու եմ իմ շաբաթական առաջադրանքները, ուսումնական ճանապարհորդությունը և վերջնական պրոեկտի ստեղծման ընթացքը։
