# Բարի գալուստ իմ էջ

## Ես Յանան եմ։ 

Ուրախ եմ ողջունել ձեզ իմ անհատական վեբ էջում, որը ստեղծվել է նախագծային ուսումնառության շրջանակներում։ Այս կայքում ես ներկայացնելու եմ իմ շաբաթական առաջադրանքները, ուսումնական ճանապարհորդությունը և վերջնական պրոեկտի ստեղծման ընթացքը։
